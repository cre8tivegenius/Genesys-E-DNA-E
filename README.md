# Genesys-E-DNA-E

## Quick Start

### Clone the Repository

```bash
git clone https://github.com/cre8tivegenius/Genesys-E-DNA-E.git
cd Genesys-E-DNA-E
```

### Install Dependencies

```bash
pip install -e .
```

### Run Tests

```bash
pytest tests/
```
